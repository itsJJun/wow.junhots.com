How to refresh your gear (one-time setup, then 2 steps)
  1. Once: download the Gear Snapshot addon, unzip it into World of Warcraft\_forever_\Interface\AddOns\ (you get a GearSnapshot folder there) and tick it in the AddOns list at character select.
  2. In game, type /reload (or just log out). The game then writes your gear, class, race, spec, level, professions and gold to a file. Open each profession window once before that, so your skill and known recipes are saved too. The spec is the one you picked in Forever Leveling BiS, if you use it.
  3. Click Load my gear (or drop the file here). The file's path is copied for you, so in the Open window press Alt+N to jump to the File name box, then Ctrl+V and Enter. It is World of Warcraft\_forever_\WTF\Account\<account>\<realm>\<character>\SavedVariables\GearSnapshot.lua. Class, spec, level and skills fill in too.
  4. Suffix prices (Gear Snapshot 1.1): Auctionator and TSM keep one price for all versions of a green, so “of Shadow Wrath” can't be priced from them. With Gear Snapshot on, run Auctionator's full scan (or click the items you want in the auction house), then /reload and load the file again. Until then, greens whose suffix price is unknown are listed but never put in your plan.
